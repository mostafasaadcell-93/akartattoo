# Akar Tattoo

Booking website for Ali Akar's tattoo studio in Hlaliyeh, Saida ([@akar.tattoo](https://instagram.com/akar.tattoo)).

- Ink-pour intro, style categories, work gallery with every angle of each piece
- 5-step booking: placement on a body map, size, references, calendar with free slots, WhatsApp hand-off
- My booking page: status, countdown, move or cancel
- Studio dashboard for Ali (footer link "Studio login", demo PIN 1998)

Single self-contained `index.html` (fonts and photos embedded). Bookings are stored in the browser for the demo.
